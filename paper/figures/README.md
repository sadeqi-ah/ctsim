# paper/figures/

`paper/paper.tex` declares `\graphicspath{{figures/}}` and includes every
figure by bare file name, so each figure must exist in this directory
before `pdflatex` runs.

Nothing in this directory except this README is committed: `.gitignore`
ignores `*.pdf`, `*.png` and `*.svg` repository-wide. The figures are
regenerated from the simulator, never stored in the history.

## Build order

From the repository root:

1. Generate the figures:

       python3 tools/regen_figures.py

   or run the individual scripts under `plots/`.

2. Copy them here under the names the paper expects:

       python3 tools/collect_paper_figures.py

3. Verify that all fourteen figures are in place:

       python3 tools/collect_paper_figures.py --check

4. Build the paper:

       cd paper && pdflatex paper.tex && pdflatex paper.tex

## Mapping

`python3 tools/collect_paper_figures.py --list` prints the authoritative
mapping. Eleven figures are generated by the plot scripts; three are
hand-drawn diagrams (`pipeline_mechanism.pdf`, `message_frame.pdf`,
`paxos_ci_example.pdf`) that no script produces and that have to be placed
here by hand.
