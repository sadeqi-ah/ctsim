# Contributing to CTSim

Thanks for your interest in CTSim. This is a research simulator released
alongside a paper; contributions that improve correctness, reproducibility, or
clarity are welcome.

## Development setup

```bash
cargo build --release
cargo test
```

For the figure scripts:

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
```

## Before opening a pull request

CI runs exactly these four checks — run them locally first:

```bash
cargo fmt --all --check
cargo clippy --all-targets -- -D warnings
cargo test --all
cargo build --release
```

- Do **not** commit generated artifacts (anything under `results/`,
  `sweep_results/`, `plots/**/results/`, or generated `*.png`/`*.pdf`/`*.csv`);
  they are ignored on purpose and are meant to be reproduced from the scripts.
- If you change simulator behavior, note which figures/tables it affects.
- Keep runs reproducible: never iterate a `HashSet` of neighbours where the
  order feeds the RNG (loss draws, capture-effect contention). Neighbour lists
  are returned sorted for this reason, and `tests/reproducibility.rs` will fail
  if a fixed seed stops reproducing a run.

## Reproducibility

Every result in the paper is regenerated by a script under `plots/`. If you add
an experiment, add a self-contained script there that (re)runs the simulator
and writes its figures next to itself, following the existing pattern in
`plots/_common.py`.

## Reporting issues

Please include the config (or sweep) file, the exact command, the simulator
version/commit, and the observed vs. expected behavior.
